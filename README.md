# Автоматическая нарезка видео и удаление тишины: Auto-Editor + FFmpeg + Docker

Набор файлов к ролику «Автоматическая нарезка видео и удаление тишины». Находит паузы в записи по громкости и собирает **черновой таймлайн** для Premiere Pro или DaVinci Resolve. Без абонентской платы, видео не уходит на чужие сервера.

Канал с материалами: [@ByteAutomate_AI](https://t.me/ByteAutomate_AI). Внедрение под ключ: @konstantin_100.

```bash
git clone https://github.com/Kavilucky/ep29-auto-editor-cut
```

## Что внутри
| Файл | Для чего |
|---|---|
| `cut_silence.bat` | Windows: перетащите видео на файл, рядом появится `<видео>_cut.xml` |
| `presets/` | четыре пресета: Premiere Pro и DaVinci Resolve × «подкаст» (порог 4%, отступ 0.2 с) и «шумная запись» (порог 8%, отступ 0.3 с) |
| `docker-compose.yml`, `watcher.py` | сервер или студия: видео в `inbox/`, таймлайн в `out_xml/` |
| `Инструкция.txt` | та же инструкция простым текстом |

## Принцип неразрушающего монтажа
Скрипт читает аудиодорожку и записывает рядом маленький файл таймлайна: какие отрезки оставить. Исходное видео **не перекодируется, не переименовывается, не перемещается и не удаляется**. В Docker папка `inbox/` подключена только для чтения. Любой стык на таймлайне двигается мышкой в монтажке.

## Как это работает
1. Auto-Editor сканирует аудио, находит участки тише порога и добавляет отступ (по умолчанию 0.2 секунды) до и после речи.
2. Результат экспортируется как XML (Premiere Pro) или FCPXML (DaVinci Resolve).
3. Импорт: Premiere Pro, Файл, Импорт; DaVinci Resolve, Файл, Импорт, Таймлайн.

## Установка (Windows)
1. Установите Python и FFmpeg, папку `bin` FFmpeg добавьте в PATH.
2. `pip install auto-editor`
3. Проверьте: `auto-editor --version` и `ffmpeg -version`. Батник сам проверяет оба и пишет по-русски, если чего-то нет.
4. Перетащите видео на `cut_silence.bat` (или на файл из `presets/`).

## Docker (студия подкастов, сервер)
```bash
docker compose up -d --build
```
Видео в папку `inbox/`, готовый таймлайн в `out_xml/`. Переменные в `docker-compose.yml`: `THRESHOLD` (4% или 8%), `MARGIN` (0.2sec или 0.3sec), `EXPORT` (`premiere` или `resolve`). После смены: `docker compose up -d --build`.

## Резервная копия (обязательно)
Правило 3-2-1: три копии записи, два носителя, один внешний диск или вне дома. Не удаляйте оригиналы, пока копия не проверена.

## Честные ограничения
- Скрипты, пресеты и compose **не запускались на живом железе** автором набора: проверьте на копии записи.
- Синтаксис флагов (`--edit audio:threshold=...`, `--export resolve`) взят из документации Auto-Editor и зависит от версии; при ошибке смотрите `auto-editor --help`. Расширение `.fcpxml` для Resolve предположительное.
- Значения порога 4% и 8% и отступа 0.3 с это стартовые точки, не замеры. Порог «−35 dB» из ролика иллюстрация.
- Формат EDL в набор не входит (в ролике упомянут): при необходимости смотрите документацию вашей версии.
- «Два часа ручной нарезки», «от 20 $ в месяц» у облачных клинеров и «три минуты» в Docker ориентиры, не замеры: время зависит от записи и железа, тарифы меняются.
- Это черновая сборка: смысловые ошибки и оговорки за вами.
